# Architecture icons

Technology logos are from [Devicon](https://github.com/devicons/devicon), under the included MIT license, and [Simple Icons](https://github.com/simple-icons/simple-icons) (RabbitMQ), under the included CC0 license. Downloaded 2026-09-30 from their public source repositories. Logos remain trademarks of their respective owners.

Client, developer, CSV, AI, AWS-service abbreviation, batch, gateway, push, and monitoring symbols are original labeled shapes generated by this project. They are not official AWS service icons.

Diagrams embed icon data and do not require external image requests. Run `node scripts/generate-project-diagrams.mjs` from the repository root to regenerate all SVG and editable draw.io files.
