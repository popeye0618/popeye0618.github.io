# 구현 검증

검증일: 2026-09-28. Windows, Node 24.19.0, Edge headless 환경.

- pnpm 10.18.3의 frozen lockfile 설치 확인.
- 정적 HTML 34개, 공개 블로그 글 3개 생성.
- 타입 검사 및 콘텐츠 메타데이터·슬러그·참조 검사 통과.
- 모든 생성 HTML의 내부 링크·이미지·앵커 검사 통과.
- 단위 테스트 4개: 한국 시간 자정 경계, 초안·잘못된 날짜, 중복 슬러그·없는 프로젝트 참조, 시리즈 순서 충돌.
- 360·768·1440px에서 홈, 프로젝트 목록·상세 3개, 이력, 블로그 목록·상세의 페이지 가로 넘침 없음.
- 한국어 캐시·작업, 영문 Spring·SQL 검색과 결과 없음·로드 실패 상태 확인.
- 테마 전환·새로고침 유지, 키보드 본문 바로가기, 이력 인쇄 PDF 생성 확인.
- 공개 임시 글 11개와 기존 3개로 목록 10+4 페이지 이동 및 카테고리 경로 확인.
- 임시 초안·미래 글은 경로·RSS·사이트맵·시리즈·관련 프로젝트·검색에 미노출.
- 긴 코드·표의 모바일 넘침 방지, 코드 클립보드 복사, Markdown 이미지와 제목 앵커 확인.
- axe WCAG 2 A/AA 및 2.1 AA 자동 검사: 주요 화면 5개 × 밝은/어두운 테마에서 위반 0건. 자동 검사가 모든 접근성을 보장하지는 않음.

임시 콘텐츠는 검증 후 제거하고 원래 콘텐츠로 다시 빌드했습니다. 캡처·PDF·검사 JSON은 로컬 `.qa/`에만 보관하며 배포하지 않습니다.

## 재현

먼저 `pnpm build` 후 `pnpm preview --port 4321`을 실행합니다. 별도 터미널에서:

```sh
pnpm test
pnpm check
pnpm test:browser
pnpm test:publication
node scripts/accessibility-check.mjs
```

Windows 브라우저 검사는 설치된 Edge를 사용합니다. 다른 운영체제는 `pnpm exec playwright install chromium`으로 브라우저를 준비합니다. `test:publication`은 임시 콘텐츠를 생성한 뒤 finally에서 제거하고 원래 사이트를 다시 빌드하므로, 다른 빌드와 동시에 실행하지 않습니다.

기존 Redis·Socket 원문은 사실 검증 전이므로 보관 안내로 제공하고, 새 블로그로 자동 재발행하지 않았습니다.
